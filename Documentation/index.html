Thank you for purchasing Pulse! This complete guide will help you install, configure API keys, and launch the platform on any server or cloud host.

⚡ 1. Quick Start (5 Minutes)

Follow these 3 simple steps to get the app running on your local machine:

Step 1: Install Dependencies

Open your command line / terminal in the extracted folder and execute:

Terminal 
npm install

Step 2: Setup Environment File

Duplicate .env.example into a new file called .env:

Terminal 
cp .env.example .env

Step 3: Launch Local Development Server

Terminal 
npm run dev

Open your web browser and navigate to: http://localhost:3000

🗄️ 3. Supabase Cloud Database Setup

Supabase provides the free backend for real-time posts, user profiles, friend connections, chat rooms, and persistent avatars.

How to Configure Supabase in 2 Minutes:

  1. Visit https://supabase.com and sign up for free.
  2. Click "New Project" and enter a project name.
  3. Go to Settings ⚙️ -> API and copy your Project URL and anon public key.
  4. Paste them into your .env file as VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.
  5. Click "SQL Editor" in your Supabase dashboard -> "+ New Query".
  6. Open the file Database/supabase-schema.sql, copy all contents, paste into the query window and click "Run"!

🌐 5. Production Deployment

You can deploy Pulse anywhere Node.js or static frontends are supported:

Deploying to Vercel / Netlify:

1. Push your code to your private GitHub repository.
2. In Vercel, import the repository.
3. Add your environment variables from .env in the project settings.
4. Click Deploy. Vercel will build and assign you a global HTTPS domain!

Building Locally:

Terminal 
npm run build

The compiled production files will be placed into the /dist folder, ready to be uploaded to any web server.

📱 6. Mobile PWA Installation

Users can install Pulse on their smartphones without going through app stores:

On Android (Chrome / Brave / Edge):
Open the website -> Tap browser menu (3 dots) -> Tap "Install App" or "Add to Home screen".

On iOS (iPhone / iPad - Safari):
Open the website in Safari -> Tap the Share button (square with arrow) -> Tap "Add to Home Screen".

❓ 7. FAQ & Troubleshooting

Q: Where are the default credentials or demo login?

Check the DEMO-LOGIN.txt file included in the root folder for sample accounts.

Q: Can I whitelabel and customize the logo and brand?

Yes, 100%! All source code is completely unencrypted and editable. Change names in index.html, metadata.json, and replace icons in public/icons/.
